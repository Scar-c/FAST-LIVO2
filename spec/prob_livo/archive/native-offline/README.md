# Prompt11 Native offline archive

Prompt11's Native FAST-LIVO2 offline reader and runner are preserved here as
historical evidence only. The Native branch was not integrated into the
canonical Prob-LIVO production tree: Prompt22 already contains the canonical
Prob offline runner and its online/offline parity contract, while Prompt11
explicitly did not establish Native LIVO offline authority.

Source branch: `prompt11-native-offline`; source commits `50e0d466`,
`a0d84a57`, and `92f26dc3`. The nested files are copied without semantic
changes. This archive is not compiled, installed, or reachable from the
canonical `include`, `src`, `tools`, or CMake production paths.
